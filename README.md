# Focuslane

Focuslane is a minimal learning planner and focus timer built for people who are learning many things at once and need structure without overwhelm.

## What it includes
- Today view with 3 daily priorities
- Learning lanes for organizing topics
- Small task cards with priority and estimate
- Focus timer for one task at a time
- Local persistence using IndexedDB
- Foundation AI onboarding template included by default

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## MVP structure
- Today: plan the day and focus on 3 priorities
- Lanes: group learning topics by area
- Focus: timer-driven work session
- Progress: quick view of what is done and what remains

## Notes
This is an MVP skeleton intended to be extended with Supabase sync, weekly reviews, and deeper accountability features later.
